# CS193-BoilerReturn
A lost-and-found platform for Purdue students.

## Project Goal
BoilerReturn aims to simplify the process of reporting and recovering lost belongings on Purdue's campus by providing students with a centralized platform to report, browse, and claim lost and found items!

## MVP Features
- Report lost and found items with details
- Browse active lost and found listings
- View individual item listings and contact info
- Store items in LocalStorage
- Mark items as successfully recovered and update the website

## Future plans for V2.0+
- Purdue student email authentication
- Email notiications for matching items
- AI Verification for the rightful owner
- Interactive campus map to show listings
